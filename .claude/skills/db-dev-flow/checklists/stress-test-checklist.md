# 压测清单

## 必测场景
- [ ] 纯写：顺序、随机、小 value、大 value
- [ ] 纯读：热集、冷集、点查、范围扫描
- [ ] 读写混合：30/70、50/50、70/30
- [ ] 长跑：≥ 12h，观察内存/磁盘/连接稳定性
- [ ] 突发流量：阶梯式加压、瞬时 10x
- [ ] 冷启动：首次加载、cache miss 期间表现
- [ ] 故障下：节点重启、磁盘慢盘、网络丢包/延迟、leader 切换
- [ ] 容量边界：磁盘 80%、90%、95% 占用下行为

## 必测指标
- [ ] 吞吐（ops/s、MB/s）
- [ ] 延迟分布：P50 / P90 / P99 / P999 / Max
- [ ] 错误率与超时率
- [ ] CPU / 内存 / 磁盘 IO util / 网络
- [ ] 内部队列长度、锁等待、GC 暂停
- [ ] 副本同步延迟（如适用）

## 报告必备
- [ ] 与基线对比，明确 Δ
- [ ] 火焰图 / pprof 截图
- [ ] 长跑曲线截图
- [ ] 异常注入下的恢复曲线
